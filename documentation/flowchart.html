Application Workflows & Logic Flowcharts

Interactive mapping of key operational pipelines, authentication checking, absence notifications, and scoped parent views.

1. Authentication and Authorization Pipeline

graph TD A[User inputs Username, Kata Laluan, and Role] --> B{Verify Login API} B -->|Invalid| C[Show Error Message in Sign In Panel] B -->|Valid| D[Generate Secure JWT Authorization Token] D --> E[Store JWT inside Client Browser LocalStorage] E --> F{Route User based on Decoded Role Scope} F -->|Administrator| G[Unlock Manage Students and Class Rosters] F -->|Teacher| H[Unlock Daily Attendance and Score Registers] F -->|Parent| I[Unlock Child Portal and Digital slip prints]

2. Daily Classroom Attendance & Email Dispatch Flow

graph TD A[Teacher selects Class level and Target Date] --> B[Roster is loaded showing assigned students] B --> C[Teacher logs Present, Absent, or Late for each student] C --> D[Teacher clicks Save Attendance Logs] D --> E[Upsert records into sqlite 'attendance' table] E --> F{Identify students marked specifically as 'Absent'} F -->|Yes| G[Fetch parent email associated with student ID] G --> H[Spool background task to dispatch immediate alert email] H --> I[Email Dispatch Simulation completed successfully] F -->|No| J[Commit logs silently and output Success response]

3. Results Publication Flow

graph TD A[Teacher inputs Student ID, Subject, Marks, and Exam Period] --> B{Verify marks boundary is between 0 and 100} B -->|No| C[Reject inputs and return boundary validation error] B -->|Yes| D{Backend resolves marks into appropriate grade boundary} D -->|Score >= 85| E[Grade: A] D -->|Score >= 70| F[Grade: B] D -->|Score >= 55| G[Grade: C] D -->|Score >= 40| H[Grade: D] D -->|Score < 40| I[Grade: F] E & F & G & H & I --> J[Insert / Update marks inside database 'results' table] J --> K[Backend triggers automatic notification email to child parent] K --> L[Parent Portal slip updated in real-time]
